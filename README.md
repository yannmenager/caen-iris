# Caen, quartier par quartier

Carte web statique montrant les contours IRIS® de Caen sur fond OpenStreetMap.

## Aperçu local

Ouvrir `index.html` dans un navigateur connecté à Internet. La carte charge Leaflet, les tuiles OpenStreetMap et la couche IRIS depuis les services de la Géoplateforme de l’IGN.

## Publication

Le site peut être publié directement avec GitHub Pages : déposer `index.html` dans un dépôt GitHub, puis choisir **Settings → Pages → Deploy from a branch**, la branche `main` et le dossier `/ (root)`. GitHub Pages publie les fichiers statiques du dépôt.
